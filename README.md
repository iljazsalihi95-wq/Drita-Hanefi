- Fikhu Hanefi
- Akide Maturidije
- Enciklopedia e Kuranit
- Hadithi
- Tefsiri
- Hudbet
- Pedagogjia Islame
- Historia Islame
- Texhvidi
- Abetarja Kuranore
- Më bëj një temë
